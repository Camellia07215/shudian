# 第4章 组合逻辑电路

> 组合逻辑：任一时刻输出仅取决于该时刻输入，无记忆、无反馈。

## 4.1 分析方法（给电路图 → 逻辑功能）

1. 由输入到输出逐级写出各门输出表达式；
2. 化简得最简与或式；
3. 列真值表；
4. 归纳逻辑功能（对照 §4.3 特征表）。
> 引擎 `analyze` 子命令自动完成 1-3 步并做冒险检查。

## 4.2 设计方法（功能需求 → 电路）

1. 定义输入/输出变量及 0/1 含义（**变量约定必须先确认**）；
2. 列真值表 → 最小项；
3. 卡诺图化简得最简式；
4. 按器件选型变换形式：与或式 →（二次取反）→ 与非-与非式；或与式 → 或非-或非式；
5. 画逻辑图；6. 检查冒险。
> 引擎 `design` 子命令自动完成 2-6 步并生成 Verilog。

## 4.3 典型组合电路特征表（功能判定依据）

| 电路 | 关键特征 | 表达式/规律 |
|---|---|---|
| 半加器 | 2 输入 2 输出，无低位进位 | S=A⊕B，C=AB |
| 全加器 | 3 输入（A,B,Ci）2 输出 | S=A⊕B⊕Ci，Co=AB+Ci(A⊕B)=AB+ACi+BCi |
| 编码器 | 2ⁿ 线→n 线，普通型要求输入互斥 | 8-3：优先编码器 74148，低电平有效，有 GS/EO/EI |
| 译码器 | n 线→2ⁿ 线，每输出对应一个最小项 | 74138（3-8）：Yᵢ'=mᵢ'；**可产生任意组合函数**（输出加与非门） |
| 数据选择器 MUX | 2ⁿ 选 1 | Y=Σ Dᵢmᵢ；**可实现任意 n+1 变量函数** |
| 数值比较器 | 7485：从高位开始比较 | 级联扩展位数 |
| 奇偶校验器 | 输出 = 各输入异或 | 9 位校验 74280 |

### 用 MSI 设计组合电路（高频考点）
- **译码器 + 门**：F = Σm(·) → F = (Π Yᵢ')'，把相关译码输出接与非门。
- **MUX**：n 个地址变量实现 n 变量函数直接连接；实现 n+1 变量函数时把剩余变量（或其函数）接到数据端。例：8 选 1 实现 4 变量函数，选 3 个变量做地址，数据端为第 4 变量的 0/1/原/反函数。

## 4.4 竞争与冒险（顶尖层调优核心）

- **竞争**：信号经不同路径到达同一门，存在时差的现象。
- **冒险（险象）**：竞争导致输出出现**不应有的窄脉冲（毛刺）**。
- 类型：**静态 1 冒险**（应恒 1 出 0 毛刺，形如 F = A + A'）；**静态 0 冒险**（应恒 0 出 1 毛刺，形如 F = A·A'）；动态冒险（多次跳变）。
- **判别法**：代数法（看是否能化为 X+X' 或 X·X' 形式）；卡诺图法（**两卡诺圈相切即存在冒险**）。
- **消除方法**：
  1. **加冗余项**（共识项）：F = AB + A'C 加 BC —— 修改设计，最常用；
  2. 输出端并小电容滤波（4~20pF 级）；
  3. 加选通脉冲，避开跳变时刻取样。
- 时序电路中冒险可能导致触发器误动作，必须消除。

> 引擎 `hazard` 子命令：枚举所有相邻最小项对，检查是否被同一主蕴含项共同覆盖；未覆盖即报静态 1 冒险并给出冗余项。

## 4.5 常见考点
1. 全加器/表决器/判奇电路分析与设计；2. 74138/74151 实现逻辑函数；3. 冒险判别与冗余项消除；4. 组合电路多方案比较（与非-与非最省器件类型）。
