# 第5章 触发器

> 触发器：具有记忆功能的双稳态元件，是时序逻辑的基本单元。

## 5.1 基本 RS 触发器

- 由两个与非门（或非门）交叉耦合构成。
- 与非门型（输入低电平有效）：R'=0,S'=1 → 置0；R'=1,S'=0 → 置1；R'=S'=1 → 保持；**R'=S'=0 禁止**（约束 RS=0）。
- 特性方程：Qⁿ⁺¹ = S + R'Qⁿ，约束 R·S = 0。
- 缺点：存在约束、直接控制（电平敏感）、抗干扰差。

## 5.2 各类触发器特性方程（必背）

| 类型 | 特性方程 | 功能 |
|---|---|---|
| RS | Qⁿ⁺¹ = S + R'Qⁿ（RS=0） | 置0/置1/保持/禁止 |
| D | **Qⁿ⁺¹ = D** | 置0/置1（无约束，最常用） |
| JK | **Qⁿ⁺¹ = JQ'ⁿ + K'Qⁿ** | 置0(J=0,K=1)/置1(1,0)/保持(0,0)/翻转(1,1)，无约束 |
| T | Qⁿ⁺¹ = T⊕Qⁿ = TQ'ⁿ+T'Qⁿ | T=0 保持，T=1 翻转 |
| T' | Qⁿ⁺¹ = Q'ⁿ | 每来一个时钟翻转（二分频） |

### 相互转换（考点）
- JK → D：J=D，K=D'；JK → T：J=K=T；D → T'：D=Q'。
- 转换方法：对比特性方程或列转换真值表求激励表达式。

## 5.3 触发方式（动作特点）

| 方式 | 特点 | 问题 |
|---|---|---|
| 电平触发（同步/钟控） | CP=1 期间输入有效 | **空翻**：一个 CP 周期内多次翻转 |
| 主从触发（脉冲） | CP=1 主触发器接收，CP 下降沿从触发器更新 | 一次变化现象（JK 主从：CP=1 期间只能变化一次） |
| **边沿触发** | 仅在 CP 上升沿/下降沿按**当时**输入更新 | 抗干扰最强，建立/保持时间约束，现代主流 |

- 逻辑符号识别：CP 端有小圆圈 = 下降沿触发；无圆圈 = 上升沿；有动态输入符号「>」表示边沿触发。

## 5.4 异步输入端
- S_D'（直接置1）/ R_D'（直接置0）：**优先级最高**，不受 CP 控制；正常工作时均接 1。

## 5.5 画波形要点（必考）
1. 先确定触发沿（上升/下降）；
2. 边沿触发只看**触发沿瞬间**的输入值；
3. 主从 JK 注意"一次变化"：CP=1 期间 J/K 多次变化时，以 Q=0 看 J、Q=1 看 K 的第一次有效变化为准；
4. 异步端优先。

## 5.6 常见考点
1. 特性方程默写与转换；2. 给定 CP 与输入波形画 Q 波形；3. 触发方式判别；4. 由触发器构成寄存器/计数器（见第6章）。
