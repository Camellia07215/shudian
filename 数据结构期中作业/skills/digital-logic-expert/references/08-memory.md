# 第8章 半导体存储器

## 8.1 分类与特点

| 类型 | 易失性 | 读写 | 典型用途 |
|---|---|---|---|
| SRAM | 易失 | 随机读写，速度快 | Cache（6 管单元，面积大） |
| DRAM | 易失 | 需**刷新**，密度高 | 主存（1 管 1 电容） |
| 掩模 ROM | 非易失 | 只读，出厂固化 | 批量产品 |
| PROM | 非易失 | 一次性编程（熔丝） | 小批量 |
| EPROM | 非易失 | 紫外擦除可重写 | 开发 |
| EEPROM(E²PROM) | 非易失 | 电擦除、按字节 | 参数保存 |
| Flash | 非易失 | 块擦除 | U盘/SSD/固件 |

- 存储容量 = 字数 × 位数（如 1K×8 = 2¹⁰ 字 × 8 位）；地址线 n 根 ↔ 2ⁿ 个字。

## 8.2 存储器扩展（计算题高频）

- **位扩展**：字数不够位宽 → 地址线/片选并联，数据线分别接。例：2 片 1K×4 → 1K×8。
- **字扩展**：地址线增加，高位地址经**译码器**产生片选。例：4 片 1K×8 → 4K×8，高 2 位地址接 2-4 译码器。
- **字位同时扩展**：先位扩成组，再字扩。
- 片数 = 目标容量 / 单片容量。

## 8.3 用 ROM 实现组合逻辑（考点）

- ROM 结构 = **与阵列（固定，地址译码产生全部最小项）+ 或阵列（可编程）**。
- n 位地址 → 2ⁿ 个最小项；每个输出位 = 若干最小项的或。
- 实现 m 个 n 变量函数：选 2ⁿ×m ROM，把真值表直接烧入或阵列。
- 例：用 ROM 实现 4 位二进制→格雷码转换、字符发生器、乘法表。

## 8.4 常见考点
1. 容量/地址线/数据线计算；2. 字位扩展方案与片选译码；3. DRAM 刷新；4. ROM 实现组合函数（画阵列图/写数据表）；5. 各类存储器选型。
