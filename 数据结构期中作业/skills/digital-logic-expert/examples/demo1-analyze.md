# 演示案例 1（基础层→进阶层）：组合电路自动分析

> 场景：学生拍了一张习题电路图（两级与非门 + 反相器），想知道它的逻辑功能。

## 对话流程

**用户**：（上传电路图）帮我分析这个电路的功能。

**助教**（多模态识别 → 规整 → 确认）：

> 我识别到：输入 A、B、C；第一级两个与非门分别实现 (AB)'、(A'C)'，  
> 第二级与非门对前两级输出取与非。即 F = ((AB)'·(A'C)')' = AB + A'C。  
> 识别结果对吗？（如不对请指出）

**用户**：对。

**助教**调用引擎：

```bash
python scripts/dlengine.py analyze --expr "F = AB + A'C"
```

引擎输出（原样引用）：

- 真值表 8 行；最小项 Σm(1,3,6,7)
- 卡诺图（格雷码标注）
- 最简 SOP：F = A'C + AB；最简 POS：F = (A+C)(A'+B)
- 冒险检查：发现 1 处静态 1 冒险
- 等价性自检：通过 ✓

**助教**（功能判定 + 知识点回链）：

> F = AB + A'C：当 A=0 时 F=C，当 A=1 时 F=B —— 这是一个 **2 选 1 数据选择器**，  
> A 为地址端，C/B 为数据端（对应 references/04 §4.3 MUX 特征）。  
> 注意引擎检出了静态 1 冒险（B=C=1 时 A 跳变），调优方案见演示案例 3。

**涉及知识点**：第2章 表达式化简 / 第4章 组合电路分析方法、数据选择器、竞争冒险。
