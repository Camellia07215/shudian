## 二、项目设计思路

本项目对标考核**顶尖层级**：不是简单的知识库问答机器人，而是覆盖
「**输入 → 分析 → 设计 → 调优 → 验证 → 评估 → 报告**」完整闭环的数字逻辑电路
全流程自动化智能体，完整包含基础/进阶/高阶层全部功能并深度延伸。

**核心设计决策：Agent 编排 + 本地确定性引擎。**

传统做法让大模型直接"口算"卡诺图化简，错误率高且无法自证。我们把课程中的确定性算法
——真值表生成、Quine-McCluskey 化简、卡诺图、静态冒险检测、全覆盖等价验证、成本评估、
Verilog 生成——全部固化为本地 Python 引擎 `dlengine.py`（零第三方依赖，结果可复现）。
大模型只做它擅长的部分：多模态输入理解（电路图照片→表达式）、意图路由、典型电路功能判定、
知识点关联讲解。**"引擎保正确，模型保体验"**，这是本项目区别于普通作业的最大差异化亮点。

覆盖知识点：教材全部十章——数制与编码、逻辑代数、门电路、组合逻辑、触发器、
时序逻辑、Verilog HDL、半导体存储器、可编程逻辑器件、小型控制器。

## 三、核心功能详解（六大模块）

### 模块① 多模态输入适配（高阶基础能力）
- 支持三类输入：电路图实拍/手绘图片、文字功能描述、真值表/逻辑表达式。
- 图片经多模态大模型识别门类型与连线关系 → 转表达式 → **用户确认门控**后进入计算，
  防止识别误差污染下游（SKILL.md 红线 3）。

### 模块② 电路自动化分析（进阶层深化）
- 输入表达式 → 引擎 `analyze` 输出真值表、最小项、卡诺图（格雷码标注）、最简 SOP/POS、
  冒险预检、等价性自检、方案评分。
- 功能判定：最简式/真值表与知识库特征表比对，识别编码器、译码器、半加器、全加器、
  数据选择器等典型电路（如演示 1 中 F=AB+A'C 被判定为 2 选 1 数据选择器）。
- 对应章节：第 2 章化简、第 4 章分析方法。

### 模块③ 电路自动化设计（高阶层核心）
- 输入功能需求（"三人多数表决器"）或真值表 → 引擎 `design` 自动完成卡诺图化简；
- **多方案生成**：与或式 / 与非-与非式 / 或非-或非式，对应不同门电路选型（德摩根定理）；
- 自动生成**可综合 Verilog 模块 + 全覆盖 testbench**；
- 对应章节：第 4 章设计方法、第 7 章 Verilog。

### 模块④ 电路自动化调优（顶尖层核心区分点 1）
- **风险排查**：引擎 `hazard` 枚举全部相邻最小项对，检测是否被同一主蕴含项覆盖，
  自动发现静态 1 冒险（卡诺图相切圈）；
- **消除方案**：依据共识定理自动给出冗余项（如 F=AB+A'C → 加 BC）；
- **性能估算**：输出门级延迟级数与最长路径分析建议；
- 对应章节：第 4 章 §4.4 竞争冒险。

### 模块⑤ 自动化验证评估（顶尖层核心区分点 2）
- 引擎 `verify` 对任意两表达式做**全输入枚举**等价性验证（2ⁿ 全覆盖测试用例）；
- 引擎 `evaluate` 从硬件成本（门数/输入端）、电路复杂度（延迟级数）、
  运行可靠性（冒险数）三维度自动评分（百分制 + 评级），生成校验报告；
- 对应章节：第 3 章参数、第 4 章冒险、方案论证方法论。

### 模块⑥ 知识点知识库（基础层保底 + 增值）
- `references/` 十章知识库与教材逐章对齐，支持概念问答、例题解析、公式查询；
- 所有计算结果自动回链对应章节（如"消险依据：02-逻辑代数 §共识定理"），
  实现结果与知识的双向对应。

## 四、技术实现方案

### 4.1 底座与封装
- 平台：DeepSeek Harness（dsh），以 **Cordis 插件**形式分发，一条命令安装：
  `dsh plugin add github:<user>/dsh-digital-logic-expert`；
- 插件入口 `lib/index.js` 递归发现 `skills/` 下的 SKILL.md，通过
  `ctx.skills.registerProvider` 注册（与官方 skill2dsh 生成插件同一契约，
  `_selftest.mjs` 8 项断言自测通过）。

### 4.2 确定性引擎 dlengine.py（≈600 行，零依赖）
| 算法 | 实现 |
|---|---|
| 表达式解析 | 递归下降（支持 '/~/并置/+/^、括号、F= 左部） |
| 化简 | Quine-McCluskey 求主蕴含项 + 必要项提取 + 分支定界最小覆盖 |
| POS | 对 F' 化简后德摩根取反（无关项参与圈并） |
| 卡诺图 | 2-4 变量格雷码文本渲染 |
| 冒险检测 | 相邻最小项对 × 主蕴含项联合覆盖检查，共识项建议 |
| 验证 | 两表达式 2ⁿ 全输入枚举比对 |
| 评估 | 成本模型（与/或/非门数、输入端数、延迟级数）+ 加权评分 |

### 4.3 工作流编排（SKILL.md）
将「输入规整→引擎计算→功能判定→调优→验证→报告生成」编排为全自动流水线，
用户一次输入即可跑完；关键节点（图片识别结果、变量约定）设用户确认门控。

### 4.4 核心提示词设计逻辑
- 红线 1：**禁止模型口算化简结果**，必须调用引擎并原样引用输出——保证正确性；
- 红线 3：图片识别必须经用户确认——多模态误差的防火墙；
- 触发词覆盖课程全部术语（卡诺图/竞争冒险/状态机/PLD…），宽窄经自测校准。

## 五、创新与亮点（差异化）

1. **全流程闭环**：不是单点工具，一次输入跑完"分析→设计→调优→验证→评估"全链路；
2. **确定性引擎背书**：化简/验证结果由算法保证，非模型臆测，且每次输出自带等价性自检；
3. **竞争冒险自动调优**：共识定理驱动的冗余项消除，直达顶尖层要求；
4. **自动验证评估**：全覆盖测试用例 + 三维评分报告，形成可量化的质量闭环；
5. **结果↔知识点双向回链**：每个结论标注教材章节出处，真正服务课程学习；
6. **工程化交付**：标准 dsh 插件结构、CLI 自测、演示脚本、文档齐全，可直接安装演示。

## 六、测试与验证

| 用例 | 输入 | 关键结果 | 验证 |
|---|---|---|---|
| 1 经典冒险电路 | F = AB + A'C | 最简式 A'C+AB；检出 011↔111 静态 1 冒险；建议加 BC | 化简自检通过；verify 消险前后 8/8 等价 ✓ |
| 2 三人表决器 | Σm(3,5,6,7) | F=AB+AC+BC；三方案；Verilog+testbench；评分 68 合格 | 全 8 输入比对通过 ✓ |
| 3 含无关项设计 | Σm(1,3,5,7,9,11,13,15)+Σd(0,2) | F=D（无关项正确参与圈并）；评分 99 优秀 | 全 16 输入比对通过 ✓ |
| 4 复合表达式分析 | F=(A+B)(A+B'+C)D+A'BC' | 真值表 16 行；SOP=A'BC'+BD+AD；POS 同步给出 | 化简自检通过 ✓ |
| 5 等价性反例 | 任意不等价表达式对 | 正确报告失配输入组合 | ✓ |

（课堂演示时现场运行用例 1→2→3，即 examples/ 中三个递进演示脚本。）

## 七、课堂演示方案

1. **演示 1（进阶层）**：上传电路图 → 识别确认 → analyze → 功能判定为数据选择器；
2. **演示 2（高阶层）**："设计三人表决器" → design → 卡诺图/三方案/Verilog/testbench；
3. **演示 3（顶尖层）**：对演示 1 电路 hazard → verify → evaluate，展示调优+验证+评分闭环，
   并对比"有/无冗余项"两方案的评分差异，讲清共识定理的工程意义。

预案：全部命令已本地跑通，输出截图存档于报告附件；若现场网络异常，
引擎为纯本地运行不受影响。

## 八、总结与收获

- **专业巩固**：把卡诺图化简、QM 表格法、竞争冒险、状态机等知识点从"会做题"
  提升到"能实现算法"的理解深度；
- **AI 工具观**：体会"模型编排 + 确定性引擎"的分工哲学——做 AI 的使用者，
  用工程手段约束模型幻觉，而不是盲目信任或拒绝；
- **工程能力**：完整的插件化开发（契约、自测、文档、演示）流程实践。
