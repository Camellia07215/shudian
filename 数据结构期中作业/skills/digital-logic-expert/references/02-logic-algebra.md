# 第2章 逻辑代数基础

## 2.1 三种基本运算

| 运算 | 表达式 | 口诀 | 国标符号要点 |
|---|---|---|---|
| 与 AND | F = A·B | 有 0 出 0，全 1 出 1 | 矩形框 "&" |
| 或 OR | F = A+B | 有 1 出 1，全 0 出 0 | 矩形框 "≥1" |
| 非 NOT | F = A' | 入 0 出 1 | 框 + 输出小圆圈 |

复合运算：与非 (AB)'、或非 (A+B)'、与或非、**异或 A⊕B = A'B+AB'**（不同为 1）、**同或 A⊙B = AB+A'B'**（相同为 1）。A⊙B = (A⊕B)'。

## 2.2 公理与基本定理

- 0-1 律：A+0=A，A+1=1，A·0=0，A·1=A
- 交换/结合/分配律（**或对与分配**：A+BC = (A+B)(A+C)，普通代数不成立）
- 互补律：A+A'=1，A·A'=0；重叠律：A+A=A，A·A=A；还原律：(A')'=A
- **德摩根定理**：(A+B)' = A'B'，(AB)' = A'+B'（可推广到 n 变量）
- **吸收律**：A+AB = A；A+A'B = A+B；AB+AB' = A
- **冗余律（共识定理）**：**AB + A'C + BC = AB + A'C**（BC 为冗余项）
  - 推论：消险——最简式加上共识项可消除静态冒险（引擎 hazard 子命令即依据此定理）。

## 2.3 三个重要规则

1. **代入规则**：等式中某变量用同一函数代入，等式仍成立。
2. **反演规则**：求 F' —— ·↔+、0↔1、原变量↔反变量（**保持运算顺序，加括号**）。
3. **对偶规则**：求 F* —— ·↔+、0↔1，变量不变。两对偶函数性质互推；F 与 F* 相等时称自对偶。

## 2.4 逻辑函数的标准形式

- **最小项 mᵢ**：n 变量全体出现且各出现一次的乘积项，共 2ⁿ 个；编号按变量取值对应二进制。性质：全体最小项之和为 1；任意两最小项之积为 0。
- **标准与或式（最小项之和）**：F = Σm(·)。
- **最大项 Mᵢ**：n 变量的和项；F = ΠM(·)。mᵢ 与 Mᵢ 互补：Mᵢ = mᵢ'。
- 无关项（约束项/任意项）：d，化简时可当 0 或 1 使用以扩大卡诺圈。

## 2.5 化简方法

### 代数化简
并项（AB+AB'=A）、吸收（A+AB=A）、消去（A+A'B=A+B）、配项（乘 (A+A') 或加冗余项）。

### 卡诺图化简（规则必背）
1. n 变量卡诺图 2ⁿ 格，行列按**格雷码**排列；几何相邻 + 逻辑相邻（上下左右、首尾、四角）。
2. 圈 1（求 SOP）或圈 0（求 POS）；每圈格数必须为 2ᵏ；圈尽量少、尽量大；每圈至少含一个未被圈过的 1；可重复圈。
3. 圈内取值不变的变量保留（1 取原变量，0 取反变量）。
4. 无关项 d 按需圈入。

### 多输出函数化简
以**共享乘积项最多**为目标，而不是各输出各自最简。

> 引擎实现：dlengine 用 Quine-McCluskey 表格法求主蕴含项并做最小覆盖，结果与手工卡诺图化简等价且可处理 5-6 变量。
