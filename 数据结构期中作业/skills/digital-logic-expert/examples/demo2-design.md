# 演示案例 2（高阶层）：从功能需求到多方案电路设计

> 场景：用户输入自然语言需求"设计一个三人多数表决器"，助教全自动完成设计闭环。

## 对话流程

**用户**：设计一个三人多数表决器，并给我 Verilog 代码。

**助教**（变量约定 → 确认）：

> 变量约定：A、B、C 分别代表三人投票（1=同意，0=反对），F=1 表示提案通过。  
> 真值表：F=1 当且仅当 ≥2 人同意 → 最小项 Σm(3,5,6,7)。确认无误后开始设计。

**助教**调用引擎：

```bash
python scripts/dlengine.py design --vars A,B,C --minterms 3,5,6,7 --module voter3
```

引擎输出（原样引用）：

- **卡诺图**（A\BC，格雷码）
- **最简式**：F = BC + AC + AB
- **多方案**：
  - 与或式：F = BC + AC + AB
  - 与非-与非式：F = ((BC)'·(AC)'·(AB)')' —— 全部用 7400 与非门即可搭电路
  - 或非-或非式：F = ((B+C)+(A+C)+(A+B))''
- **调优检查**：无静态冒险；成本 4 门 / 9 输入端 / 延迟 2 级；综合评分 68（合格）
- **Verilog**：

```verilog
module voter3(A, B, C, F);
    input  A, B, C;
    output F;
    assign F = (B & C) | (A & C) | (A & B);
endmodule
```

- **全覆盖 testbench**：枚举 8 种输入并 $display 输出
- **自动验证**：化简结果 vs 真值表，全 8 种输入比对通过 ✓

**助教**（知识点回链）：

> 设计流程对应 references/04 §4.2 六步法；与非-与非变换依据德摩根定理  
> （references/02 §2.2）；Verilog 属数据流建模（references/07 §7.2）。  
> 若要实验箱搭建，推荐与非-与非方案：一片 7400（4×二输入与非）即可实现。

**涉及知识点**：第4章 设计方法、多方案变换 / 第7章 Verilog 建模与 testbench。
