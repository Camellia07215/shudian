# 第1章 数制与编码

## 1.1 数制

- **基数 r 进制**：数码 0~(r-1)，位权 r^i。常用：二进制(2)、八进制(8)、十进制(10)、十六进制(16)。
- 多项式表示：N = Σ kᵢ·rⁱ。

### 数制转换

| 转换           | 方法                             |
| ------------ | ------------------------------ |
| r 进制 → 十进制   | 按位权展开求和                        |
| 十进制整数 → r 进制 | 除 r 取余，余数倒序排列                  |
| 十进制小数 → r 进制 | 乘 r 取整，整数正序排列（可能无限循环，需截断并说明误差） |
| 二进制 ↔ 八进制    | 3 位一组（小数点左右分组，不足补 0）           |
| 二进制 ↔ 十六进制   | 4 位一组                          |

例：(11010.101)₂ = 26.625；(69.75)₁₀ = (1000101.11)₂。

## 1.2 带符号数的机器码

| 码制 | 正数      | 负数           | 备注                          |
| -- | ------- | ------------ | --------------------------- |
| 原码 | 符号位0+数值 | 符号位1+数值      | 0 有 +0/-0 两种表示              |
| 反码 | 同原码     | 符号位1，数值位按位取反 | 0 有两种表示                     |
| 补码 | 同原码     | 反码+1         | 0 唯一；n 位补码范围 -2ⁿ⁻¹ ~ 2ⁿ⁻¹-1 |

- **补码加减**：符号位参与运算，[X±Y]补 = [X]补 ± [Y]补（减 = 加负数的补码）。
- **溢出判据**：同号相加结果变号 / 双符号位（变形补码）两位不同即溢出。

## 1.3 常用编码

### BCD 码（二-十进制编码）

| 码型     | 位权      | 特点                      |
| ------ | ------- | ----------------------- |
| 8421 码 | 8,4,2,1 | 最常用，有权码；1010~1111 为禁用码组 |
| 2421 码 | 2,4,2,1 | 自补码（9 的补码按位取反）          |
| 余 3 码  | 无权      | 8421+0011；自补码，加法进位自然    |
| 余3循环码  | 无权      | 循环+自补                   |

### 格雷码（Gray / 循环码）

- **任意相邻两组码只有一位不同** → 抗干扰、消除卡诺图相邻性编码、异步计数器防毛刺。
- 二进制→格雷：G = B ⊕ (B>>1)（最高位不变，其余 Gi = Bi ⊕ Bi+1）。
- 卡诺图行/列标注必须使用格雷码顺序 00-01-11-10。

### ASCII 与奇偶校验

- ASCII：7 位，共 128 字符；'0'=30H，'A'=41H，'a'=61H。
- 奇校验：信息位+校验位中 1 的个数为奇数；偶校验反之。只能检奇数个错，不能纠错。

## 1.4 常见考点

1. 小数转换的精度截断问题；2. 补码运算与溢出判断；3. BCD 加法修正（>9 或产生进位时 +0110）；4. 格雷码与二进制互转；5. 奇偶校验码设计。
