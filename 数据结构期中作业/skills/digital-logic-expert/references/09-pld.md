# 第9章 可编程逻辑器件（PLD）

## 9.1 PLD 的共同结构

输入缓冲（提供原/反变量）→ **与阵列** → **或阵列** → 输出缓冲。
符号约定：交叉点 "×"= 编程连接，"●"= 固定连接，空白 = 断开。

## 9.2 发展脉络与对比（必背）

| 器件 | 与阵列 | 或阵列 | 输出结构 | 特点 |
|---|---|---|---|---|
| PROM | 固定 | 可编程 | 固定 | 译码器思想，阵列利用率低 |
| **PLA** | **可编程** | **可编程** | 固定 | 最灵活，但软件支持差 |
| **PAL** | **可编程** | 固定 | 可编程(部分) | 一次编程，结构简单速度快 |
| **GAL** | 可编程 | 固定 | **OLMC 宏单元可配置** | E²CMOS 可重复擦写，兼容 PAL |
| CPLD | 多个 PAL 块 + 可编程互连 | — | 宏单元 | 集成度高，延迟可预测 |
| **FPGA** | **LUT 查找表 + 可编程互连 + IOB** | — | 可配置 | 基于 SRAM（多数），密度最高，需上电配置 |

## 9.3 FPGA 要点

- 基本单元：CLB（含 LUT + 触发器）、IOB、互连资源；LUT 本质是 16×1 SRAM（4 输入）。
- 配置方式：主串/从串/边界扫描；掉电丢失 → 外挂配置 PROM。
- 与 CPLD 对比：FPGA 寄存器丰富适合复杂时序/数据通路；CPLD 组合资源丰富、上电即工作、延迟确定。

## 9.4 设计流程
设计输入（原理图/HDL）→ 综合 → 适配（布局布线）→ 时序/功能仿真 → 编程下载（JTAG）。

## 9.5 常见考点
1. 各器件与/或阵列可编程性对比表；2. 用 PAL/GAL 实现组合/时序逻辑；3. FPGA 的 LUT 原理（LUT 实现任意 n 变量函数 = 存储真值表，与 ROM 思想一致）；4. FPGA vs CPLD 选型。
