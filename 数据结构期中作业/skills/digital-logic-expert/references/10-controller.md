# 第10章 小型控制器与数字系统设计

## 10.1 数字系统划分

数字系统 = **控制器（控制单元）+ 数据通路（受控单元）**。
- 控制器：按时序发出控制信号（本质是有限状态机 FSM）。
- 数据通路：寄存器、ALU、MUX 等完成数据处理。

## 10.2 ASM 图（算法状态机图，核心工具）

三种符号：
| 符号 | 名称 | 含义 |
|---|---|---|
| 矩形框 | 状态框 | 一个状态 + 该状态内**无条件**输出/操作（Moore 输出写在此） |
| 菱形框 | 判断框 | 按输入条件分支（2 路或多路） |
| 圆角矩形框 | 条件输出框 | 某分支下**条件**输出（Mealy 输出写在此），挂在判断框之后 |

- 一个 ASM 块（状态框+其下属判断/条件输出）= 一个时钟周期。
- ASM 图 → 硬件：状态编码 → 状态机设计（同第6章流程）→ 数据通路按操作表配置寄存器。

## 10.3 控制器实现方式

| 方式 | 结构 | 特点 |
|---|---|---|
| 计数器型 | 状态寄存器用计数器 | 状态迁移规则简单时最省 |
| MUX 型 | 每状态位用 MUX 选次态 | 通用、便于修改 |
| **微程序控制** | 控制存储器(ROM)存微指令 | 规整、易扩展：微指令 = 控制字段 + 下址字段 |
| PLD/FPGA 实现 | HDL 描述 FSM | 现代主流（见第7章三段式模板） |

## 10.4 经典设计实例（课程常见）

1. **交通灯控制器**：状态 = 主干道绿/黄 + 支道绿/黄，定时器计数，传感器输入优先。
2. **自动售货机**：投币金额累加（数据通路）+ 找零/出货控制（FSM）。
3. **乘法控制器**：ASM 描述"加-移位"算法，计数器控制迭代次数。
4. **序列检测/脉冲分配器**。

## 10.5 设计要点
1. 先画 ASM 图再编码，不要直接写状态转移表；
2. 状态编码优先二进制/格雷码/独热码（one-hot：FPGA 中常用，译码简单速度快）；
3. 必须考虑复位态与无效状态自启动；
4. 控制器输出分 Moore（稳态有效）与 Mealy（边沿/条件有效），注意毛刺对受控单元的影响（回链第4章冒险）。

## 10.6 常见考点
1. 由文字描述画 ASM 图；2. ASM → 状态机 → Verilog 三段式实现；3. 微程序控制器结构与微指令格式；4. 完整小型系统（如交通灯）方案设计。
