# 第6章 时序逻辑电路

> 时序逻辑：输出取决于**当前输入 + 电路原状态**；含存储元件（触发器）。
> 分类：同步（统一时钟）/ 异步；Mealy 型（输出依赖输入和状态）/ Moore 型（输出仅依赖状态）。

## 6.1 分析方法（给电路 → 功能）

1. 写三组方程：**驱动方程**（各触发器输入表达式）、**输出方程**；
2. 代入特性方程得**状态方程** Qⁿ⁺¹ = f(输入, Qⁿ)；
3. 列**状态转换表**（枚举全部现态×输入组合）；
4. 画**状态转换图**与时序图；
5. 判断功能（几进制计数器？移位？序列检测？）；
6. 检查**自启动**：无效状态能否在有限拍内回到有效循环。
> 异步时序：状态方程必须标注时钟条件（哪一级触发沿到来才更新）。

## 6.2 典型时序电路

### 寄存器
- 数码寄存器（并行存取）；**移位寄存器**（串入-串出/并出，74194 双向移位：S1S0=00 保持/01 右移/10 左移/11 置数）。
- 应用：串并转换、环形计数器（模=n，需自启动修正）、扭环计数器（模=2n，无相邻多码变化）。

### 计数器
| 类型 | 特点 |
|---|---|
| 异步二进制 | 逐级翻转，T' 级联；速度慢但结构简单 |
| 同步二进制 | 各触发器同一 CP，Jᵢ=Kᵢ=Q₀Q₁…Qᵢ₋₁；速度快 |
| 同步十进制 | 8421 BCD，模 10 |
| 74161/74163 | 4 位同步二进制，LD' 同步置数、CR'(161 异步/163 同步清零)、ET·EP 使能、RCO 进位 |

### 用 74161 构成任意模 N 计数器（高频考点）
- **反馈清零法**：计到 N（异步清零）或 N-1（同步清零）时清零；异步清零态为过渡态。
- **反馈置数法**：计到某状态时 LD' 有效，置入初值；如计 0..N-1：在 N-1 处置数 0000。
- 级联：模相乘（两片 74161 最多 256 进制）。

## 6.3 同步时序设计流程（状态机设计，必考大题）

1. 题意 → **原始状态图**（设状态，画迁移）；
2. **状态化简**：合并等价状态（输出相同且次态等价）；
3. **状态分配**（状态编码）：尽量使相邻迁移编码相邻；确定触发器个数 n ≥ ⌈log₂S⌉；
4. 选触发器类型 → 列状态转换表/激励表 → 卡诺图求**驱动方程与输出方程**；
5. 画逻辑图；6. **检查自启动**（把无效状态代入状态方程看次态）。
> D 触发器：激励表即次态表（D=Qⁿ⁺¹），最省事；JK：用激励表（Q→Q⁺：0→0:J=0,K=d；0→1:1,d；1→0:d,1；1→1:d,0）。

## 6.4 典型设计实例
- 序列检测器（如检测 1011，Mealy/Moore 两解）、串行加法器、交通灯控制器、自动售货机。
- 顺序脉冲发生器、序列信号发生器（计数器+MUX/译码器）。

## 6.5 常见考点
1. 计数器模值分析与任意模改装；2. 移位寄存器应用；3. 状态机全流程设计 + 自启动检查；4. Mealy/Moore 判别；5. 异步计数器波形。
