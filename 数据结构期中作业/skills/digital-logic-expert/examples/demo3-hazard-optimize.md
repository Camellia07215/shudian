# 演示案例 3（顶尖层）：竞争冒险检测、调优与全流程验证评估

> 场景：承接演示案例 1 的电路 F = AB + A'C，展示顶尖层差异化能力：  
> 自动调优（冒险消除）+ 自动验证（等价性全覆盖）+ 多维评估报告。

## 对话流程

**用户**：案例 1 那个电路说有冒险，帮我排查并给出改进方案，验证改进前后功能一致。

**助教**调用引擎（三步闭环）：

```bash
# ① 冒险检测
python scripts/dlengine.py hazard --expr "F = AB + A'C"
# ② 消险前后等价性全覆盖验证
python scripts/dlengine.py verify --expr1 "AB+A'C" --expr2 "AB+A'C+BC"
# ③ 两方案多维评分对比
python scripts/dlengine.py evaluate --expr "AB+A'C"
python scripts/dlengine.py evaluate --expr "AB+A'C+BC"
```

引擎输出（原样引用）：

**① 冒险检测**

```
最简 SOP: F = A'C + AB
检测结果：发现 1 处静态 1 冒险 ⚠
  - 输入 011 ↔ 111，变量 A 变化时输出可能出现毛刺
    消除方案：添加冗余项 BC
消险后的稳健表达式：F = BC + A'C + AB
```

**② 等价性验证**

```
全覆盖验证：共 8 种输入组合
结果：两表达式功能完全等价 ✓ (8/8 通过)
```

**③ 评分对比**

| 方案               | 门数 | 输入端 | 延迟  | 冒险  | 成本/复杂/可靠 | 综合分 | 评级  |
| ---------------- | -- | --- | --- | --- | -------- | --- | --- |
| 原方案 F=AB+A'C     | 4  | 7   | 3 级 | 1 处 | 15/18/25 | 58  | 需优化 |
| 消险方案 F=AB+A'C+BC | 5  | 9   | 3 级 | 0   | 10/13/40 | 63  | 合格  |

**助教**（讲解 + 知识点回链）：

> - 原理：B=C=1 时 F = A+A'，A 跳变经两条路径延迟不同 → 输出瞬时 0 毛刺  
>   （references/04 §4.4 静态 1 冒险，卡诺图上表现为两圈相切）。
> - 消除：由**共识定理** AB+A'C+BC = AB+A'C（references/02 §2.2），  
>   加入冗余项 BC 后相切圈被覆盖，毛刺消除；verify 证明功能不变。
> - 工程取舍：消险多花 1 个与门（成本分 15→10），但可靠性分 25→40 满分，  
>   综合分 58→63 反超原方案——用于驱动时序负载时毛刺是致命的，必须消险。

**涉及知识点**：第4章 竞争冒险判别与消除 / 第2章 共识定理 / 方案评估方法论。
